## Numerical and compatibility findings

- `x_2_t` and `t_2_x` access index `nx2t` above the final knot although valid knots end at `nx2t-1`; this is an out-of-bounds read. Below the first knot they return failure without writing the output. Preserve the in-range mathematics; record and test an explicit boundary policy rather than reproducing undefined memory behavior.
- C conversion callers ignore failed interpolation status. The current Python excludes out-of-range samples; that is a documented difference, not parity.
- `xtc_icc_insert_correlation_level` contains replacement and deletion of crossing levels. Python currently rejects nonmonotone edits. The missing workflow must be ported with visible feedback and undo.
- Scalar stacking uses `(center-width/2, center+width/2]` bins and assigns a sample to the first matching bin, even if bins overlap. It computes population standard deviation. Do not replace this with generic overlapping-window averaging.
- Fisher statistics, VGP calculations, palaeomagnetic binary writing and axis-division helpers are called from external code. Their exact implementations and file structures must be recovered before claiming equivalent scientific output.
- Y limits, linear/log scale and inversion load from `.yrr`. FT/FD overlays remain pending.

## Acceptance gates

1. Every row has a reviewed implementation or documented runtime replacement.
2. Every original keyboard operation has a visible mouse action; keyboard shortcuts may remain optional.
3. Scientific outputs match accepted C fixtures within stated tolerances. Boundary/error differences are explicit.
4. Complete `.xtci` projects open/save with shared models, all parameters, ancillary records and styles.
5. Mouse workflows, undo/redo, protected levels, and macOS/Windows packaging are verified.

## Missing source required for latest-version parity

Complete XTC 4.5.x source tree, `pmp_included_headers.inc`, `specials.inc`, their transitive headers, shared scientific libraries (including `fisher_statistics`, `vgp`, binary structures/writers, axis division), build files, and representative expected outputs.

The machine-readable inventory also lists external call names, includes, declared-but-missing functions, and menu strings. External call names include standard C/runtime functions; they are not all missing scientific routines.
